# Park Solitaire Frontend

Frontend-only React/Vite prototype based on the supplied Figma screenshot.

## Run

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite.

## Screens
Splash, Login, Register, Partner Dashboard, Clients, Client Details, Visit Updates, Complaints, Payment Status, Admin Dashboard.

This version uses mock data. Backend/MySQL will be connected in the next phase.
